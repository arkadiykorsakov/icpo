# icpo

Веб-система на Laravel 13 для ведения картотеки Интерпола: учёта зарегистрированных преступников, поиска по любому набору признаков и ведения архива.

## Назначение

Система хранит данные по каждому зарегистрированному преступнику:

- фамилия, имя, отчество (среднее имя);
- кличка;
- рост и вес;
- цвет волос и глаз;
- особые приметы;
- гражданства;
- место и дата рождения;
- последние места жительства;
- знание языков;
- место и дата смерти;
- преступные профессии.

## Возможности

- **Выборка по любому подмножеству признаков.** Поиск можно вести по одному признаку или по их произвольной комбинации. Незаполненные условия фильтра не учитываются.
- **Перенос «завязавших» в архив.** Лицо, прекратившее преступную деятельность, переносится в архив. Данные при этом сохраняются и остаются доступными для поиска.
- **Удаление только после смерти.** Удалить запись можно только у умершего лица. Для остальных доступен лишь перенос в архив.

Административная панель реализована на Filament 5.

## Запуск

### Требования

- Docker
- Docker Compose

PHP, Composer, Node.js и PostgreSQL устанавливать на хостовую машину не требуется.

### Запуск контейнеров

```bash
docker compose up -d --build
```

### Установка зависимостей

```bash
docker compose exec app composer install
```

### Генерация ключа приложения

```bash
docker compose exec app php artisan key:generate
```

### Установка Filament

```bash
docker compose exec app composer require filament/filament:"^5.0" -W
docker compose exec app php artisan filament:install --panels
```

### Выполнение миграций

```bash
docker compose exec app php artisan migrate
```

### Остановка приложения

```bash
docker compose down
```

## Адреса сервисов

| Сервис | Адрес |
|---|---|
| Приложение | http://localhost:8080 |
| Filament | http://localhost:8080/admin |
| Vite | http://localhost:5173 |
| Mailpit | http://localhost:8025 |
| pgAdmin | http://localhost:5050 |

Mailpit и pgAdmin запускаются отдельно:

```bash
docker compose --profile tools up -d
```
